# Changelog

All notable changes to the GeoFS Esri World Imagery userscript are documented here.

## [1.0.0] - Initial Release

### Added
- Added support for Esri World Imagery in GeoFS.
- Added automatic imagery initialization when the simulator loads.
- Added a loading and retry mechanism to handle GeoFS initialization.
- Added console messages to report success or errors.
- Added support for imagery tiles up to zoom level 19, where available.
- Added installation instructions for Tampermonkey and manual console use.
- Added a public GitHub repository for the project.

### Notes
- Imagery quality and availability vary by location.
- The script depends on GeoFS exposing the required imagery API.
- This is an unofficial community project and is not affiliated with GeoFS or Esri.
